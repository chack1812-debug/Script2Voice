# GUI リデザイン（案A: マスター/ディテール＋部屋俯瞰図）設計書

日付: 2026-06-11
ベース: 初版 GUI（`2026-06-10-gui-launcher-acoustic-lab-design.md`、実装済み `9cce27c..4bfd3d4`）
デザイン選定: `docs/gui-design-proposals.html` の**案A（タブ型・正統進化）**を採用
（案B〜E は不採用。案Bのワンスクリーン化は将来の再検討対象）

## 目的

1. タブ1を**マスター/ディテール2ペイン**化し、台詞全文・行設定を確認しながら試聴できるようにする
2. タブ2の中心に**部屋の2D俯瞰図**を置き、聴取者・話者を**ドラッグ**で配置できるようにする
   （「パラメータ設定中に音響のイメージがつかない」への対策）
3. **部屋寸法 W/D/H をそれぞれ独立に設定**できるようにする（スライダー＋数値直接入力）
4. **⏹停止ボタン付きの再生バー**を両タブ共通で下部に置く（現状は停止手段が無い）

UI 再構成のみで、DSP・合成・ライブラリ（s2v-core/audio/engines/script2voice lib）は**変更しない**。

## タブ1「台本」— 2ペイン化

```
┌──────────────────────────────────────────────────┐
│ [📂開く] パス表示  [✔]自動再読込                       │
├──────────────────┬───────────────────────────────┤
│ 行リスト(38%)      │ 選択行の詳細                      │
│  No/キャスト/先頭   │  台詞全文（折り返し表示）            │
│  （クリックで選択）  │  シーン名・部屋寸法・listener 設定    │
│  ⚠警告は行内表示    │  cast: pan/distance/height/volume │
│                  │  [▶ この行を試聴(大)]               │
│                  │  [🎛 ラボでこの行を調整 →]           │
├──────────────────┴───────────────────────────────┤
│ [▶一括実行][⏹ｷｬﾝｾﾙ] 進捗バー n/全行  [📁出力フォルダ]   │
├──────────────────────────────────────────────────┤
│ ▶ ⏹ | 再生中: preview_0002.wav | ▶A ▶B   ←再生バー   │
└──────────────────────────────────────────────────┘
```

- 左=行リスト（No/キャスト/台詞先頭。シーン列は詳細側に移動して幅を節約）。
  パース警告は従来どおりリスト上部に行番号付きで表示。
- 右=選択行の詳細: **台詞全文**（display_text、折り返し）、シーン情報
  （シーン名・実効部屋寸法・listener_dx/dy/z・reverb_wet）、実効 cast パラメータ
  （pan/distance/height/volume、行内臨時パラメータ適用後の値）、[▶試聴]。
- **[🎛 ラボでこの行を調整]**: タブ2へ切替え、ラボの音源を「台本の行」に設定。
  その行の raw（プレビュー合成結果）が未取得なら**自動でプレビュー合成を開始**してから
  使えるようにする（合成完了までラボの[▶処理して試聴]は無効のまま＝既存の input None 動作）。
- 一括実行・キャンセル・進捗・出力フォルダは**タブ1下部の全幅ストリップ**に移動
  （モック図では右ペイン内だったが、台本全体への操作のため全幅が適切と判断）。
- 行未選択時の右ペインは「行を選択してください」のプレースホルダ。

## タブ2「音響ラボ」— 部屋俯瞰図中心

```
┌──────────────────────────────────────────────────┐
│ 音源: ●台本の行 N（試聴済み） ○WAVファイル [選択...]      │
├────────────────────────┬─────────────────────────┤
│ 部屋俯瞰図(46%・上から見た図)│ プリセット [▼][適用]        │
│ ┌────────────────┐     │ 部屋 W [====|--] [25.0]m  │
│ │  前壁(反射率で色濃淡) │     │ 部屋 D [======|] [45.0]m  │
│ │     🔊 ←ドラッグ   │     │ 部屋 H [==|----] [18.0]m  │
│ │    ⌒破線(経路)     │     │ 聴取高 z / 話者高さ / 残響倍率│
│ │   👤 ←ドラッグ     │     │ pan [+25.0]° 距離 [2.00]m │
│ │                  │     │ [▶ 処理して試聴(大)]        │
│ └────────────────┘     │ @scene行 [📋コピー]         │
│ 25×45×18m  RT60 1.1s   │ 履歴 [▶A][▶B][クリア]       │
│                        │  #3 [A] … ▶ 呼び戻す 💾    │
├────────────────────────┴─────────────────────────┤
│ ▶ ⏹ | 再生中: lab_0004.wav | ▶A ▶B                  │
└──────────────────────────────────────────────────┘
```

### 部屋俯瞰図（新規モジュール `room_view.rs`）

- egui の painter で描画。**上から見た図**: x=幅W（右+）、y=奥行D（上=前方+）。
  ペインに収まるよう等比スケーリング（部屋の縦横比を保持、余白に寸法ラベル）。
- **前壁**（図の上辺）を config の `front_wall.reflection_coeff` に応じた濃さで太く描き、
  他の壁・床素材は描き分けない（v1 は前壁の示唆のみ。色凡例は不要）。
- **聴取者👤**: 位置 = 部屋中央 + (listener_dx, listener_dy)。ドラッグで
  `listener_dx/dy` を更新（部屋内にクランプ）。
- **話者🔊**: 位置 = 聴取者 + (distance·sin(pan), distance·cos(pan))（pan 0°=正面=+y、
  +が右）。ドラッグで `pan`/`distance` を**逆算**して更新:
  `distance = max(0.1, √(vx²+vy²))`、`pan = atan2(vx, vy) × 180/π`（範囲 −180°〜+180°、
  聴取者の後方への配置も可）。部屋内にクランプ。
- 聴取者と話者の間に破線、図の下に `W×D×H m ／ RT60 n.n s` を表示。
- **RT60 表示**: `s2v_audio::acoustics::compute_reverb_params`（公開済み）を
  現在の W/D/H と config の `early_reflections`・`sound_speed`・`sample_rate` で呼んで算出。
  このため `App` が `AudioConfig` のクローンを保持する（Jobs から取り出さず起動時に複製）。
- 図⇔スライダー/数値は**双方向同期**（どちらを動かしても他方に即反映）。

### パラメータ（W/D/H 個別設定 — 今回の必須要件）

| 項目 | コントロール | 範囲 |
|---|---|---|
| 部屋 W（幅） | Slider ＋ **DragValue（数値直接入力）** | 2.0〜60.0 m |
| 部屋 D（奥行） | 同上 | 2.0〜80.0 m |
| 部屋 H（高さ） | 同上（俯瞰図には現れないが RT60 に反映） | 2.0〜30.0 m |
| 聴取高さ listener_z | Slider＋DragValue | 0.2〜5.0 m |
| 話者高さ height | 同上 | 0.0〜5.0 m |
| 残響倍率 reverb_wet | 同上 | 0.0〜3.0 |
| pan | **DragValue 中心**（図のドラッグが主操作） | −180〜+180 ° |
| distance | 同上 | 0.1〜30.0 m |

- W/D/H は**1行ずつ独立**（現行どおり `LabParams.room_w/d/h` 個別フィールド。
  Grid の1行1項目に変更し、DragValue を併設）。
- W/D 変更時、聴取者・話者が部屋外に出る場合は位置をクランプし pan/distance を再計算。
- listener_dx/dy のスライダーは**廃止**（図のドラッグに一本化。数値は図の近くに小さく表示）。
- pan の範囲を従来の ±90° から **±180°** に拡大（図で後方配置が可能になるため）。
  `@scene` 行・行内パラメータ生成は従来どおり（値域拡大のみ）。

### その他タブ2

- プリセット・[▶処理して試聴]・@scene 行コピー・履歴（A/B・呼び戻す・書き出し・クリア）は
  従来機能のままレイアウトのみ右ペインに整理。
- プリセット適用時も図が即追随（apply_preset → 図再描画）。

## 共通: 再生バー（新規 `transport.rs`）

- 両タブ共通の下部固定バー: **[▶]**（直近の再生対象をもう一度）／**[⏹停止]**／
  「再生中: ファイル名」（停止中は「—」）／**[▶A][▶B]**（履歴選択時のみ有効。
  タブ1からも押せる）。
- `App` に `now_playing: Option<String>`（表示名）を持たせ、再生開始/停止で更新。
  `Player::stop()` は実装済みのため配線のみ。再生終了の自動検知は v1 では行わない
  （表示は最後に再生開始したファイル名のまま。⏹で「—」に戻る）。
- 既存のログフッター（collapsing「実行ログ」）は再生バーの**下**にそのまま残す。

## 変更しないもの

- ライブラリ4クレート＋script2voice lib（API 追加・変更なし。
  `compute_reverb_params` は既に公開済みのため呼ぶだけ）
- jobs.rs / audio_play.rs / presets.rs / history.rs / script_model.rs / scene_line.rs の
  ロジック（scene_line は pan 値域拡大の影響なし＝f64 をそのまま出力）
- CLI、台本仕様、config.toml / presets.toml の形式

## エラー処理・エッジケース

| 状況 | 挙動 |
|---|---|
| 図のドラッグで部屋外へ | 部屋境界にクランプ（聴取者・話者とも） |
| W/D 縮小で話者/聴取者がはみ出す | クランプして pan/distance を再計算 |
| distance が 0 に近づくドラッグ | 0.1m を下限にクランプ |
| 🎛ボタンで raw 未取得 | 自動プレビュー合成を開始（busy 中は従来どおり多重実行防止）。失敗時は既存の preview_error 表示 |
| 行未選択で🎛 | ボタン無効 |
| 再読込で選択行消滅 | 既存どおり selected/preview_raw クリア → 詳細ペインはプレースホルダに戻る |

## テスト方針

- **ロジックを UI から分離してユニットテスト**（新規 `room_view.rs` 内）:
  - 座標変換: (pan, distance, listener_dx/dy) → 図上座標 → 逆変換の往復一致
  - クランプ: 部屋外ドラッグ・W/D 縮小時の再計算・distance 下限
  - pan ±180° の境界（後方配置）
- RT60 表示値が `compute_reverb_params` の rt60 と一致（呼び出しの単体テスト）
- 描画・ドラッグ操作そのものは手動スモーク（チェックリストを計画に含める）
- 既存テスト（scene_line 往復・history 等）は全て不変で PASS のこと
