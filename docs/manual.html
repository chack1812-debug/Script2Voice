Script2Voice 取扱説明書・操作マニュアル

本書は、台本ファイルから音声合成・空間音響処理・字幕(SRT)・編集タイムライン(FCPXML)・ ミックス済み音声(WAV)を一括生成するツール Script2Voice（Rust 版）の 取扱説明書です。インストールから台本の書き方、出力物の確認方法までを解説します。 早期反射・物理残響などの空間音響パラメータの詳細解説（第5章）も本書に統合されています。

1. Script2Voice とは

Script2Voice は、テキスト形式の「台本ファイル」を読み込み、登場人物（キャスト）ごとに 指定した音声合成エンジン（VOICEVOX / AivisSpeech / XTTS）で音声を生成し、 パン（左右の定位）・距離・残響などの空間音響処理を加えたうえで、 以下の成果物を自動生成するツールです。

  • 各台詞ごとの音声ファイル（ステレオ WAV、空間音響処理済み）
  • 台詞をまとめてミックスした音声ファイル full_dialogue.wav
  • 字幕ファイル subtitles.srt
  • 動画編集ソフト用タイムライン timeline.fcpxml（Final Cut Pro 互換）

台本ファイル（テキスト）を1つ用意するだけで、ナレーション動画やボイスドラマなどの 音声・字幕・編集タイムラインを一括して作成できることが最大の特長です。

2. 準備・セットアップ

2.1 ビルド方法

Rust ツールチェイン（cargo）がインストールされた環境で、プロジェクトのルートディレクトリから次を実行します。

# デバッグビルド（開発・動作確認用）
cargo build

# リリースビルド（実運用向け、最適化あり）
cargo build --release

ビルドが成功すると、実行ファイルは target/release/script2voice.exe（Windows の場合）に生成されます。

動作確認やテストには cargo test --workspace を実行してください。 全クレート（s2v-core / s2v-engines / s2v-audio / s2v-export / script2voice）の ユニットテストと統合テスト（E2E テスト）が一括で実行されます。

2.2 音声合成エンジンの起動

台本内で使用する音声合成エンジンは、Script2Voice を実行する前に あらかじめ起動しておく必要があります（Script2Voice は HTTP 経由でエンジンに接続します）。

エンジンの自動起動・自動停止について
config.toml の各エンジンの設定に exe_path （実行ファイルのパス）を指定しておくと、Script2Voice は処理開始時に 接続確認を行い、応答がない場合は自動的にそのプロセスを起動して、 起動完了まで待機します（最大約30秒）。
また、処理が終了する際（成功・失敗を問わず）には、Script2Voice 自身が 起動したエンジンプロセスを自動的に停止します。
もともと起動済みだったエンジン（exe_path を介さずに 手動で起動していたエンジン）は停止されません。
この機能を使わない場合は、これまで通り Script2Voice を実行する前に 手動でエンジンを起動しておいてください。
エンジン名台本内の指定名既定の URL起動方法の例
VOICEVOX voicevox http://127.0.0.1:50021 "C:\Program Files\VOICEVOX\vv-engine\run.exe" を実行
AivisSpeech aivis http://127.0.0.1:10101 "C:\Program Files\AivisSpeech\AivisSpeech-Engine\run.exe" を実行
XTTS (Coqui TTS) xtts http://localhost:8020 python -m xtts_api_server --port 8020 --lowvram --model-version v2.0.2 --speaker-folder ./assets/speakers

台本内で 使用しているエンジンのみが起動・利用されます （未使用のエンジンは起動チェックされません）。

2.3 config.toml の設定

実行時の挙動（接続先 URL、音響パラメータ、同時実行数、BGM 設定など）は プロジェクトルートの config.toml で設定します。 主な項目は次の通りです。

セクション / キー説明
[voicevox] urlVOICEVOX エンジンの接続先 URL
[aivis] urlAivisSpeech エンジンの接続先 URL
[xtts] urlXTTS エンジンの接続先 URL
[voicevox] / [aivis] / [xtts] exe_path （省略可）各エンジンの実行ファイルのパス。指定すると、未起動時に Script2Voice が自動的に起動し、終了時に自動的に停止します （例: exe_path = "C:\\VOICEVOX\\run.exe"。 TOML 内ではバックスラッシュを \\ と二重に書くか、 'C:\VOICEVOX\run.exe' のようにシングルクォートで囲みます）。 省略した場合は、これまで通り事前に手動で起動しておく必要があります。
[audio] sample_rate出力音声のサンプリングレート (Hz)
[audio] microphone_spacing仮想ステレオマイクの間隔 (m)。既定 0.2m
[audio] sound_speed音速 (m/s)。両耳間の到達時間差 (ITD) の計算に使用
[audio] air_absorption_coeff空気吸収の係数。距離に応じた高音域の減衰の強さ
[audio] room_size場面の既定の部屋の広さ (0.0〜1.0)。@scene の room_size や寸法指定で上書き可
[audio] reverb_wet残響量の倍率（既定 1.0＝物理量どおり）。部屋寸法と壁素材から算出される残響基準値に掛ける。@scene で上書き可
[audio] reference_dist / reference_gain_db / max_gain_db距離減衰や音量の基準値・上限値
[audio] mic_directivity / mic_angle仮想マイクの指向性の強さと向き（外開き ORTF 配置）。値が大きいほど定位の広がりが強くなる
[audio.early_reflections]空間音響（早期反射・物理残響）の設定。enabled（ON/OFF）、ear_height（聴取者の床からの高さ）、listener_offset、room_dims_min/room_dims_max（room_size 0→1 に対応する部屋寸法 [幅,奥行,高さ]m）、early_level、wet_distance_slope、および 5 素材（floor/ceiling/front_wall/back_wall/side_walls）の reflection_coeff・absorption_cutoff_hz。詳細は第5章 空間音響パラメータ解説を参照
[audio.engine_volume_offsets]エンジンごとの音量補正係数 (例: voicevox = 1.2)
[concurrency]エンジンごとの同時合成数、音響処理の並列数（0 = CPU コア数を自動使用）
[bgm] crossfade_s / se_fade_out_sBGM のクロスフェード秒数、SE のフェードアウト秒数
config.toml はプロジェクトルートに同梱のサンプル（config.toml）をコピーして、 接続先 URL や音響パラメータを環境に合わせて調整してください。
config.toml の配置場所について
--config オプションを省略した場合、Script2Voice は 実行ファイル（script2voice.exe）と同じフォルダにある config.toml を自動的に読み込みます（カレントディレクトリではありません）。
そのため、script2voice.exe と config.toml を同じフォルダに置いておけば、 どの場所から実行してもその設定ファイルが使われます。 別の設定ファイルを使いたい場合のみ --config で明示的にパスを指定してください （指定したパスが最優先されます）。

3. 基本操作

3.1 コマンドラインの使い方

script2voice <台本ファイルのパス> [--config <設定ファイルのパス>]
引数 / オプション説明
<台本ファイルのパス>（必須）処理対象の台本テキストファイルのパス
-c, --config <パス>設定ファイル (config.toml) のパス。省略時は実行ファイルと同じフォルダの config.toml が使用される

実行例:

script2voice .\scripts\episode01.txt
script2voice .\scripts\episode01.txt --config .\my_config.toml

設定ファイルの探索順序は次の通りです。

  1. --config で明示的に指定したパス（最優先）
  2. （省略時）実行ファイル（script2voice.exe）と同じフォルダの config.toml

3.2 処理の流れ

  1. プロジェクトフォルダの作成 — 台本ファイルと同じフォルダの中に、台本ファイル名（拡張子なし）と同名のフォルダを作成します。以後の出力はすべてこのフォルダに格納されます。
  2. 台本の解析 — @scene / @pause / @asset / @cast / @script の各セクションを解析し、場面（シーン）と台詞・コマンドのリストを構築します。
  3. エンジンの起動確認 — 台本内で使用されているエンジン（VOICEVOX / AivisSpeech / XTTS）にのみ接続を試みます。
  4. 音声合成 + 空間音響処理（並列実行） — 台詞ごとに音声合成 → ステレオ化（パン・距離・残響などの DSP 処理）を行い、audio/ フォルダに個別の WAV ファイルとして出力します。
  5. タイムラインの構築 — @pause の設定や同時発声指示（#数字）に従って、各台詞・BGM・SE の再生開始時刻を計算します。
  6. 各種ファイルの書き出し — 字幕(SRT)、編集タイムライン(FCPXML)、ミックス済み音声(WAV) を出力します。

3.3 出力されるファイル

処理が完了すると、台本ファイルと同じ場所に作成されたプロジェクトフォルダ （例: episode01/）に、以下のファイル・フォルダが生成されます。

パス内容
audio/voice_0001.wav, voice_0002.wav, ...台詞ごとに空間音響処理済みのステレオ WAV ファイル（連番）
timeline/subtitles.srt台詞のタイミングと表示テキストをまとめた字幕ファイル
timeline/timeline.fcpxml各音声クリップ・BGM・SE の配置を記録した FCPXML 形式の編集タイムライン（Final Cut Pro 等で読み込み可能）
full_dialogue.wavすべての台詞をタイミング通りに重ね合わせてミックスしたステレオ音声
FCPXML は Final Cut Pro やそれに対応した編集ソフトに読み込むことで、 台詞・BGM・SE がタイムライン上に自動配置された状態から動画編集を開始できます。

4. 台本ファイルの書き方

台本ファイルはプレーンテキストで記述します。台本は次の5種類のセクションから構成され、 これらを場面ごとに繰り返し記述できます。

  1. @scene — 場面の開始を宣言する
  2. @pause — 無音時間（間）の設定
  3. @asset — BGM・SE 素材フォルダの指定
  4. @cast — 登場人物（キャスト）の定義
  5. @script — 台詞・各種音声出力の指示
# で始まる行はコメント、または特殊コマンドとして扱われます（詳細は 4.6 コマンド一覧を参照）。空行は無視されます。

4.1 @scene セクション — 場面の宣言

場面（シーン）の先頭で宣言します。場面名と音響場（部屋の大きさ・聴取者の位置・残響量）を指定できます。いずれのパラメータも省略可能です。

@scene 01_オープニング room_size=0.3 reverb_wet=1.0
@scene ホール room_w=25 room_d=45 room_h=18 listener_dy=-15 listener_z=1.1
場面名@scene の直後に書く任意の文字列（出力フォルダ名や FCPXML のクリップ識別等に利用）
room_size部屋の広さの簡易指定。0.0〜1.0、小さいほど狭い空間。省略時は config.toml の既定値。寸法（下記 room_w/d/h）が優先される
room_w / room_d / room_h部屋の幅・奥行・高さ（m）。3つすべて指定すると room_size より優先。座標は x=幅(左右)・y=奥行(前後＝聴取者の正面)・z=高さ
listener_dx / listener_dy聴取者（ステレオマイク中心）の部屋中央からのオフセット（m。+x=右、+y=前）。省略時は config の値。前壁に寄せるとホール的な前方反射が強まる
listener_z聴取者（マイク中心）の床面からの絶対高さ（m）。省略時は config の ear_height
reverb_wet残響量の倍率（既定 1.0＝物理量どおり）。部屋寸法と壁素材から算出される残響基準値に掛ける。0 で残響なし。省略時は config の既定値
残響の長さ・量、および床・壁・天井からの早期反射は、部屋寸法と各面の素材（反射率・吸音特性）から 物理的に決まります。素材の既定値や各面の調整は config.toml の [audio.early_reflections] で行います （壁・天井の反射率を 0 にすると屋外＝床反射のみ・ほぼ無残響）。詳しくは 第5章 空間音響パラメータ解説を参照してください。

各場面には @asset / @cast / @script の各セクションを 含めることができます。新しい @scene が現れると、そこまでの内容で ひとつの場面が確定し、次の場面の解析が始まります。

4.2 @pause セクション — 間（無音）の設定

台詞と台詞の間、話者交替時、段落の区切りに挿入する無音時間（ミリ秒）を設定します。

@pause
sentence 200
cast 500
paragraph 1000
sentence ****同じ話者の台詞間に ****ms の無音を挿入する
cast ****話者が交代するときに ****ms の無音を挿入する
paragraph ****段落の区切り（#paragraph コマンド使用時）に ****ms の無音を挿入する

省略した項目は既定値（sentence: 200ms、cast: 500ms、paragraph: 1000ms）が使用されます。

4.3 @asset セクション — 素材フォルダの指定

BGM・効果音 (SE) の音源ファイルを格納したフォルダを指定します。

@asset
bgm_dir = ./assets/bgm
se_dir = ./assets/se
bgm_dirBGM 音源フォルダのパス（絶対パス・相対パスとも可。空白を含むパスも指定できます）
se_dir効果音 (SE) 音源フォルダのパス

4.4 @cast セクション — キャスト（登場人物）の定義

台本中で発声する役（キャスト）ごとに、話者・音声合成エンジン・各種パラメータを定義します。

@cast
役名:話者名:スタイル,エンジン名,パラメータ1=値1,パラメータ2=値2,...
「スタイル」と「エンジン名」の区切りは カンマ（,）です。 コロン（:）で区切ると正しく解析されず、エンジン名が誤認識されます。 書式は必ず 役名:話者名:スタイル,エンジン名,... の形を守ってください。

記述例:

@cast
めたん:四国めたん:ノーマル,voicevox,pan=-30,distance=1.0,volume=1.0
まい:まい:ノーマル,aivis,pan=30,distance=1.0,volume=0.9
解説:Gitta Nikolina:default,xtts,language=ja,pan=0,distance=1.0
役名@script 内で発言者として指定する名前
話者名音声合成エンジン側の話者（スピーカー）名
スタイル発声スタイル（VOICEVOX / AivisSpeech のみ。XTTS の場合は default を指定）
エンジン名voicevox / aivis / xtts のいずれか
language発声言語。XTTS のみ有効（例: ja, en）。VOICEVOX/AivisSpeech は常に日本語
pan左右の定位（単位: 度）。+ で右方向、- で左方向
distance聴取者（マイク）までの距離（単位: m）
height話者の床面からの絶対高さ（単位: m）。省略時は聴取者と同じ高さ。床・天井反射の幾何に影響する。行内臨時パラメータ（例 めたん(height=0.3):…）では、その行限定の加算オフセットとして働く
volume音量の倍率（既定 1.0）
その他のパラメータ各エンジン固有のパラメータ（speedScale, pitchScale など）をそのまま 名前=値 の形式で指定可能
pan（方向）・distance（距離）・height（高さ）は、外開き（ORTF 的）に配置した 仮想ステレオマイク（マイク間隔は config.toml の microphone_spacing、既定 0.2m）でとらえた音として、 到達時間差（ITD）・音量差（ILD）・床/壁/天井の早期反射を計算して定位を再現します。 pan は仕様どおり + で右、− で左に定位します。定位の強さ（広がり）は config.toml の mic_directivity / mic_angle で調整できます（値が大きいほど広がりが強い）。 詳しくは第5章 空間音響パラメータ解説を参照してください。

4.5 @script セクション — 台詞と音声指示

場面内で実際に発声される台詞や、BGM・SE・無音などの指示を記述します。

役名:台詞テキスト
役名(臨時パラメータ):台詞テキスト
#コマンド
（空行）

基本の台詞

めたん:こんにちは、まいさん。

役名 は @cast セクションで定義済みの役名と一致させてください。

臨時パラメータ（その台詞だけ値を変える）

カッコ内に パラメータ名=±値 の形式で記述すると、 @cast で設定された値に対する増減（オフセット）として、その台詞限定で適用されます。 複数指定する場合はカンマで区切ります。 

めたん(pan=15,distance=2):このセリフだけ定位と距離が変わります
めたん(pitchScale=+0.01,speedScale=+0.5):感情の高まりを声の変化で表現する例

4.6 コマンド一覧 (#行)

# で始まる行はコマンドとして解釈されます。

コマンド書式説明
コメント# コメント文（# の直後に空白）その行は無視されます
BGM 再生開始#bgm_start ファイル名.wav指定した BGM を再生開始します。ファイルは @asset の bgm_dir から検索されます
BGM 停止#bgm_stop再生中の BGM を停止します（クロスフェードあり）
効果音 (SE)#se ファイル名.wav指定した効果音を挿入します。ファイルは @asset の se_dir から検索されます
無音の挿入#pause ****その位置に ****ms の無音を挿入します
段落区切り#paragraph段落の切れ目を示し、@pause の paragraph 設定の無音を挿入します
同時発声#数字（例: #2）続く指定数の台詞を同時刻から同時に発声させます（複数キャラが同時に話す演出など）

同時発声の例（2人が同時に驚く演出）:

#2
めたん(delay=500):きゃっ！何かしら今の音！？
まい:な、なんなのだ！？ 地震なのだ！？

delay=**** を臨時パラメータとして指定すると、 同時発声の基準時刻からその台詞の発声開始を ****ms 遅らせることができます。

4.7 ルビ表記・台詞の書き方

誤読されやすい単語は、シングルクォーテーションで囲んで '表記:読み' の形式で指定すると、 音声合成では「読み」、字幕表示では「表記」が使われます。 

めたん:'東京:とうきょう'に行く
項目結果
音声合成（読み上げ）に使われるテキストとうきょうに行く
字幕(SRT)に表示されるテキスト東京に行く

複数のルビを1つの台詞に含めることもできます。

解説:「'深淵:しんえん'より出でし'者:もの'、'黎明:れいめい'の光を掲げよ」……？

4.8 サンプル台本

5. 空間音響パラメータ解説（早期反射・物理残響）

本章は、早期反射（イメージソース法）と 距離依存の残響量制御に関する設定パラメータの意味・追加場所・調整方法をまとめたものです。 すべて config.toml の数値設定のみで調整でき、プログラムの再ビルドは不要です。

5.1 この機能は何か

従来の音響処理は「直接音（左右の定位・距離減衰）→ いきなり拡散リバーブ（残響の尾）」 という構成で、その間を埋める早期反射が存在しませんでした。 人間の耳は、直接音の直後（数ミリ秒〜数十ミリ秒）に届く床・壁・天井からの最初の反射を 直接音と融合させて、「音が実在の空間の、その場所にある」と接地・外在化します。 これが無いと、左右の方向は分かっても距離・上下が曖昧になり、音が「宙に浮いて」聞こえます。

この機能は、部屋を箱（直方体）としてモデル化し、床・天井・前後左右の 6面の一次反射を計算して直接音の直後に加えます。これにより接地感が生まれます。 部屋の大きさは既存の room_size に連動します。

上下方向（仰角）の定位は耳介の形状（HRTF）に依存し、通常の2chステレオでは原理的に再現できません。 本機能は水平面のモデルですが、床反射などで「接地感」を補うことで「浮き」を軽減します。

5.2 追加場所（config.toml）

設定は実行ファイル（script2voice.exe）と同じフォルダにある config.toml の [audio] セクション内、新しいサブセクション [audio.early_reflections] に記述します。 配置は [audio] のスカラー設定（mic_angle など）すべての後、 かつ [audio.engine_volume_offsets] の前です。 

[audio]
# ... sample_rate, microphone_spacing, ... , mic_directivity, mic_angle まで ...
mic_directivity = 0.2
mic_angle = 30.0

[audio.early_reflections]
enabled = true
ear_height = 1.2
listener_offset = [0.0, 0.0]
room_dims_min = [4.0, 5.0, 3.0]
room_dims_max = [25.0, 45.0, 18.0]
early_level = 1.0
wet_distance_slope = 0.1
floor      = { reflection_coeff = 0.5,  absorption_cutoff_hz = 3500.0 }
ceiling    = { reflection_coeff = 0.6,  absorption_cutoff_hz = 6000.0 }
front_wall = { reflection_coeff = 0.85, absorption_cutoff_hz = 10000.0 }
back_wall  = { reflection_coeff = 0.40, absorption_cutoff_hz = 4000.0 }
side_walls = { reflection_coeff = 0.70, absorption_cutoff_hz = 8000.0 }

[audio.engine_volume_offsets]
# ...
このセクション全体、あるいは個々の項目を省略しても動作します（後方互換）。 省略した項目は上記の既定値が使われます。既存の config.toml をそのまま使っても問題ありません。

5.3 空間モデルの考え方

5.3.1 座標系

箱（部屋）：x∈[0,W]、y∈[0,D]、z∈[0,H]（単位：メートル）
X 軸＝幅（左右。+x が右）／Y 軸＝奥行（前後。+y が聴取者の正面）／ Z 軸＝高さ（上下。+z が上）

部屋の寸法 [W, D, H] は、room_size（0.0〜1.0）に応じて room_dims_min と room_dims_max の間を線形補間して決まります。 room_size=0.0 で最小（小スタジオ）、1.0 で最大（大ホール）です。

5.3.2 聴取者＝マイク位置

聴取者の位置 = ステレオマイクペアの中心です。部屋の水平中央 （listener_offset でずらせる）・高さ ear_height に置かれます。 実際の収音は、その中心から左右に microphone_spacing/2（既定 ±0.1m）離れた2本のマイクで行われます （microphone_spacing は [audio] 既存設定）。

音源は、聴取者から見て台本の pan（方位角）・distance（距離）・height（高さ）の位置に 置かれます（height 省略時は聴取者と同じ高さ。5.7節参照）。各面の鏡像（イメージソース）から届く反射の 遅延・音量・左右方向がこの幾何から自動計算されます。

5.3.3 処理の流れ

音響処理は次の順で行われます。早期反射はこの2番目に挿入されました。

直接音（定位・距離減衰）
  → 早期反射（6面の一次反射）
  → 拡散リバーブ（残響の尾）
  → リミッター（音割れ防止）

5.4 パラメータ詳細

5.4.1 全体・部屋・聴取

パラメータ既定値意味・効果
enabledtrue 早期反射機能の ON/OFF。false にすると早期反射は一切付加されず、従来とまったく同じ出力になります。
ear_height1.2 聴取者（マイク）の高さ[m]。床・天井反射の遅延に影響します。値が小さいほど床が近く＝床反射が早く・強くなります（例：着席1.2、立位1.6程度）。
listener_offset[0.0, 0.0] 聴取者を部屋中央から動かすオフセット [左右, 前後][m]。左右にずらすと左右の壁反射が非対称になります。前にずらす（前壁に近づける）と前壁反射が早く・強くなり、ホールの「最前列」的な前方反射が得られます。
room_dims_min[4.0, 5.0, 3.0] room_size=0.0 のときの部屋寸法 [幅, 奥行, 高さ][m]。既定はラジオ収録スタジオ程度の小部屋。
room_dims_max[25.0, 45.0, 18.0] room_size=1.0 のときの部屋寸法[m]。既定は約2000席のコンサートホール相当（体積≒2万m³級）。
部屋寸法は room_size で min〜max を線形補間します。room_size 自体は [audio]・各シーン・台本の臨時パラメータで指定できる既存の設定です（拡散リバーブにも連動）。
大きな部屋（room_size 大）では壁が遠いため壁反射の遅延が長くなり、聴取者が中央だと 「早期反射」というより後部残響に近づきます。その範囲では主に床・天井反射が接地感を担います。 大ホールでも前方からの早期反射を強めたい場合は listener_offset の前後成分で前壁に寄せてください。

5.4.2 距離による残響（D/R：直接音／残響比）

パラメータ既定値意味・効果
early_level1.0 早期反射全体の音量倍率。1.0 が物理基準。上げると反射が強く＝空間が「生き生き」するが、過大だと付帯音・濁りが出ます。下げると控えめになります。
wet_distance_slope0.1 音源が遠いほど拡散リバーブ（残響）を増やす度合い。実効残響量 = reverb_wet × (1 + slope × 距離)（上限0.9）。値を大きくすると遠い音源がより残響的になり距離感が強調されます。既定 0.1 は従来の固定値と同じ＝挙動変化なし。

D/R（直接音と残響の比）は距離感の重要な手がかりです。直接音は距離に応じて素直に減衰し、 早期反射（early_level）と拡散残響（wet_distance_slope）が相対的に増えることで、 「遠いほど残響に包まれる」自然な距離感を作ります。

5.4.3 面ごとの素材（反射率・吸音）

反射面を 5つの素材グループに分け、それぞれに2つの値を設定します。インラインテーブル （{ reflection_coeff = …, absorption_cutoff_hz = … }）で記述します。

キー反射率 (reflection_coeff)吸音カットオフ (absorption_cutoff_hz)
floor（床）0.53500 Hz
ceiling（天井）0.66000 Hz
front_wall（前壁）0.8510000 Hz
back_wall（後壁）0.404000 Hz
side_walls（左右の側壁）0.708000 Hz
項目範囲の目安意味・効果
reflection_coeff0.0 〜 1.0 その面の反射の強さ。0 でその面の反射を無効化、1 で減衰なしの強い反射。高いほど明瞭で硬い響き、低いほど吸音された落ち着いた響き。
absorption_cutoff_hz例 2000 〜 Nyquist(24000) 反射時のローパス（高域吸音）のカットオフ周波数[Hz]。低いほど高域が削れて柔らかい素材（カーペット・カーテン等）、高いほど高域も反射する硬い素材（コンクリート・ガラス等）。Nyquist 付近にすると吸音は実質無効。
既定では前壁を高反射（0.85 / 10kHz）にしています。これはコンサートホールで ステージ側（演者の背後）の壁の反射が強いことを模したものです。後壁は吸音寄り（0.40 / 4kHz）にしています。 左右の側壁は同一素材として扱います（位置は listener_offset で左右非対称にできます）。

5.5 チューニング指針

すべて config.toml の数値変更のみ。試聴しながら少しずつ調整してください。

狙い・症状調整
まだ「浮く」感じが残るfloor.reflection_coeff を上げる／early_level を上げる／ear_height を少し下げて床を近づける
反射が強すぎる・付帯音や濁りが気になるearly_level を下げる／各面の reflection_coeff を下げる
空間を広く／狭くしたいroom_size（部屋寸法に連動）を上げる／下げる
素材を柔らかく／硬くしたい該当面の absorption_cutoff_hz を下げる（柔）／上げる（硬）
遠近感（距離感）を強めたいwet_distance_slope を上げる
前方からの反射を強めたい（ホール感）front_wall.reflection_coeff を上げる／listener_offset の前後成分で前壁に寄せる
機能を一時的に切りたいenabled = false

5.6 互換性・注意点

  • 後方互換[audio.early_reflections] セクションや個々の項目を省略しても動作し、省略分は既定値が使われます。
  • 回帰なしenabled = false の出力は、本機能追加前と完全に同一です。
  • 配置運用ビルドでは config.toml を実行ファイルと同じフォルダに置いてください（--config 省略時はそこを参照します）。
  • 本機能は Rust 版独自の拡張で、Python 版には早期反射はありません（意図的な差異）。
  • 各反射は3D経路長で遅延・距離減衰を、水平方位で左右差（ITD/ILD）を計算します。上下方向は水平面に畳み込みます。

5.7 台本(scene)で部屋を指定する

config.toml の [audio.early_reflections] は全体の既定値・素材を決めますが、 部屋の大きさと聴取者の位置は台本の @scene 行で場面ごとに指定できます。 これにより「ホール」「小部屋」「屋外」などを場面単位で切り替えられます。

@scene パラメータ意味・効果
room_size 0.0〜1.0 の簡易指定。room_dims_min〜room_dims_max を補間して寸法を決める。省略時は config 既定。
room_w / room_d / room_h 部屋の幅・奥行・高さ[m]。3つすべて指定すると room_size より優先。座標は x=幅(左右)・y=奥行(前後＝正面)・z=高さ。
listener_dx / listener_dy 聴取者（マイクペア中心）の部屋中央からのオフセット[m]（+x=右、+y=前）。省略時は config の listener_offset。前壁に寄せるとホール的な前方反射が強まる。
listener_z 聴取者（マイク中心）の床面からの絶対高さ[m]（listener_dx/dy の中央オフセットとは違い絶対値）。省略時は config の ear_height（既定1.2）。床・天井反射の遅延に効く。
reverb_wet 残響量の倍率（5.8節参照）。場面ごとに残響の効きを調整できる。 
@scene ホール room_w=25 room_d=45 room_h=18 listener_dy=-15 listener_z=1.1 reverb_wet=1.0
@scene 小部屋 room_size=0.1
@scene 屋外 room_w=50 room_d=50 room_h=30 reverb_wet=0.0
話者ごとの位置（聴取者から見た pan＝方向、distance＝距離、height＝高さ）は @cast で指定します。 @scene は「部屋」と「その中での聴取者の立ち位置・高さ」を、@cast は「聴取者から見た各話者の位置・高さ」を決めます。

話者の高さ（@cast height）

話者の高さは @cast 行の height=**（床面からの絶対高さ[m]）で指定します。 省略時は聴取者と同じ高さになります（後方互換）。話者を高く/低く置くと、床・天井反射の遅延・距離が変わります。

書き方意味
@cast 行 height=1.7その話者の基準の高さを 1.7m（床から）に設定。
行内 A(height=0.3):台詞その行限定の加算（基準＋0.3m）。pan/distance の臨時パラメータと同じ扱い。
高さは早期反射の床/天井反射の幾何にのみ効きます（Sabine 残響＝5.8節には影響しません）。値は部屋の高さ room_h 内にクランプされます。
屋外にするには、config の [audio.early_reflections] で壁・天井の reflection_coeff を 0 にします （床のみ反射）。これにより 5.8節の物理計算で残響もほぼ無くなります。場面によって屋内/屋外を変えたい場合は、現状は 素材が config 全体共通のため、屋外専用の config.toml を用意して使い分けてください。

5.8 残響の物理導出と reverb_wet

拡散リバーブ（残響の尾）は、部屋寸法と各面の素材から物理的に導出されます。手動の固定値ではありません。

  • 残響長 RT60：Sabine の式 RT60 ≈ 0.161 × 体積V ÷ 総吸音A で算出（A は 面積×吸音率の総和、吸音率 α = 1 − reflection_coeff²）。0.05〜12秒にクランプ。大きい/反射的な部屋ほど残響が長い。
  • プリディレイ：平均自由行程 4V/S から算出（上限50ms）。
  • 残響基準量 wet_base：1 − 平均吸音率。吸音的な部屋ほど小さく、反射的な部屋ほど大きい。屋外（壁吸音）では 0 に近づく。
パラメータ既定意味・効果
reverb_wet1.0 物理基準量 wet_base への倍率。実効残響量 = reverb_wet × wet_base × (1 + wet_distance_slope × 距離)（上限0.9）。1.0で物理どおり、下げるとドライ寄り（ナレーションの明瞭さ確保等）、0で残響なし。config.toml の [audio] reverb_wet または @scene で指定。
仕様変更（非互換）：reverb_wet は以前の「絶対的な残響ミックス量(0〜1)」から 「物理基準量への倍率(既定1.0)」へ意味が変わりました。素材・寸法から残響が決まるようになったため、 以前の台本・config の reverb_wet 値そのままでは響きが変わります。必要に応じて再調整してください。
素材（reflection_coeff／absorption_cutoff_hz）は早期反射と拡散残響の両方を同時に決めます。 反射率を上げると早期反射が強まり、残響も長く・大きくなります（物理的に一貫）。

6. トラブルシューティング

症状主な原因と対処
「台本ファイルが見つかりません」と表示される 台本ファイルのパスが間違っています。実行コマンドに渡したパスとファイルの存在を確認してください。
「キャスト '○○' が未定義です。スキップします。」と表示される @script 内で使用している役名が @cast セクションで定義されていません。表記揺れ（全角/半角、空白等）がないか確認してください。
「engine '...' not registered」「合成失敗」と表示される @cast 行の書式が 役名:話者名:スタイル,エンジン名,... になっているか確認してください（コロンとカンマの混同に注意）。また、対象の音声合成エンジンが起動済みか、config.toml の URL が正しいかも確認してください。
「ミックス対象の音声が存在しません」と表示され full_dialogue.wav が生成されない すべての台詞の音声合成・音響処理が失敗しています。上記の合成失敗の原因を解消してから再実行してください。
定位（左右の広がり）が指示より強い／弱いと感じる 定位は pan の角度に加えてマイク指向性の効きで決まります。config.toml の [audio] mic_directivity / mic_angle を下げると広がりが穏やかに、上げると強くなります（既定は控えめ寄りに調整済み）。pan は + が右、− が左です。
音が宙に浮いて聞こえる／距離感・上下感が弱い 床・壁・天井の早期反射が接地感を与えます。[audio.early_reflections] の floor.reflection_coeff や early_level を上げる、@scene で部屋寸法（room_w/d/h）や聴取者高さ（listener_z）を指定する等で調整できます（第5章 空間音響パラメータ解説参照）。
処理が遅い／メモリ消費が大きい config.toml の [concurrency] セクションで、各エンジンの同時合成数や音響処理の並列数 (audio_process) を環境に合わせて調整してください。
「出力ファイルのいずれかが使用中のため、今回の生成一式を連番 _N で保存します」と表示される 前回の出力（full_dialogue.wav / timeline/*.srt・*.fcpxml / audio/voice_*.wav）を動画編集ソフト等で開いたまま再実行すると、ファイルが使用中で上書きできません。この場合プログラムは異常終了せず、今回の生成一式すべてを共通の連番 _N（例 full_dialogue_1.wav, audio/voice_0001_1.wav, timeline/timeline_1.fcpxml, timeline/subtitles_1.srt）で保存します。FCPXML は同じ _N の音声を参照するので整合性は保たれます。既定名の前世代ファイルはそのまま残ります。元の名前で出力したい場合は、開いているアプリを閉じてから再実行してください。
