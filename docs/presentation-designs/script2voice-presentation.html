Script2Voice // Rust Edition 03 / Architecture
Script Format

台本ファイルの構造

Sections & Commands
@pause文・キャスト・段落ごとの間（無音）を設定
@assetBGM / SE 素材フォルダを指定
@cast登場人物・エンジン・定位・距離を定義
@scene場面・部屋の広さ・残響量を宣言
@script台詞本体と音声指示を記述
# 行#bgm / #se / #pause / #paragraph 等の命令
Sample Script
@cast めたん:四国めたん:ノーマル,voicevox,pan=-30,distance=1.0 まい:まい:ノーマル,aivis,pan=30,distance=1.0 @scene 01_オープニング room_size=0.3 reverb_wet=0.5 @script #bgm_start morning_breeze.wav めたん:こんにちは、まいさん。 めたん(delay=500):きゃっ！何かしら今の音！？ #se thunder_distant.wav #pause 1500 めたん:'東京:とうきょう'にも響いたのかしら…# ルビ #bgm_stop #paragraph まい:そろそろ向かいましょうか。

Script2Voice // Rust Edition 05 / TTS Engines
Spatial Audio Engine

空間音響処理 — 早期反射・物理残響

Box Room Model
🔊
🎧
W×D×H: room_size pan: 方位角 dist: 距離 reverb_wet: 残響量
Processing Chain
1
直接音
左右の定位・距離減衰・空気吸収
2
早期反射（6面の一次反射）
床・天井・前後左右の鏡像から接地感を生成
KEY
3
拡散リバーブ
部屋寸法と壁素材から導いた残響の尾
4
リミッター
音割れ防止・出力レベル調整
部屋を箱（直方体）としてモデル化し、聴取者＝ステレオマイク中心に。
直接音の直後に届く早期反射が「音が宙に浮く」のを防ぎ、実在の空間にいる接地感・外在化を生む。
